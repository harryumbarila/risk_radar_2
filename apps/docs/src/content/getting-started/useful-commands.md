# Useful Commands

Below are the key commands used in the project, along with their descriptions:

- **`yarn build`** → Runs the build process for all workspaces using
  **Turborepo**.
- **`yarn dev`** → Starts the development mode across all workspaces with
  **Turborepo**.
- **`yarn docs`** → Starts the documentation site by running `dev-docs` in the
  `@denali/docs` workspace.
- **`yarn commit`** → Launches the **git-cz** commit workflow to help use
  conventional commits.
- **`yarn format`** → Formats all files using **Prettier** for code consistency.
- **`yarn lint`** → Runs **ESLint** across the codebase to detect and fix
  issues.
- **`yarn sync-packages`** → Uses **syncpack** to fix mismatched dependencies
  across workspaces.
- **`yarn test:e2e`** → Runs end-to-end (E2E) tests using **Turborepo**.
- **`yarn test:unit`** → Runs unit tests using **Turborepo**.
- **`yarn type-check`** → Verifies TypeScript types across the project using
  **Turborepo**.

These commands help streamline development, ensure consistency, and automate
common tasks across the monorepo. 🚀
